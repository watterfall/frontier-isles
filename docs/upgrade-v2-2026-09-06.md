# 领域碰撞第二轮迭代：以好奇心组织探索

用户校正：避免形式化改进；科学探索遵循 AI native 原则；游戏化调动内在动力；加强跨领域主题与碰撞；大幅提升岛屿、路径与细节交互。

## 本轮改变

- 移除四步表单门槛、完成比例和实践印记。既有九字段笔记保留为可回看的旧记录，新增探索围绕自由追问和观察展开。
- 六组跨学科主题组织问题群岛，显示 xFrontier 的实际编辑关系。可点击岛屿、阅读航线、从当前问题分叉、回到自己的思考。
- 岛屿用稳定的海岸与等高线辨认；连线区分编辑类比、个人思考路径和未验证 AI 提案。距离与高度不表示相似度或科学价值。
- 给高风险类比增加具体辨别提示，例如：频谱相似不等于相同因果机制，天然蛋白的折叠不等于求解最坏情形复杂度问题。这些是本站阅读提示，不冒充上游证据。
- AI 接入以当前问题、用户意图、最近笔记、MCP 来源为上下文；可调用只读问题查询工具寻找第三领域，再返回跨域线索、竞争解释或可区分解释的试验。用户决定跟进哪条提案，无固定步骤。
- 本机实际模型运行接回探索航迹；预测与边界笔记可选，未作事前预测明确记录为 null，运行后不允许补填先验预测。
- 数学桥可以直接前往两端真实岛屿；主海图的岛屿地形也增加多层等高线，复用原纹理烘焙，不增加逐帧绘制工作。

## AI 连接与边界

本地预览尚未配置语言模型，界面明确显示“AI 尚未连接”，不以预制模板冒充 AI。真实模型联网推理质量尚未验证。

服务器环境配置：

```sh
FI_EXPLORER_API_KEY=...  # 仅服务端
FI_EXPLORER_MODEL=...   # 明确指定支持 Responses + function calling + JSON schema 的模型
FI_EXPLORER_BASE_URL=https://api.openai.com/v1  # 可选
```

需要已有用户会话登录，避免无身份的公开付费代理。每人每分钟最多 5 次、同一人一次在途、全局最多 4 次在途；每次最多 3 轮模型调用和 3 次只读工具调用。请求可停止，模型输出不得调用写工具或代码执行。点击 AI 操作前界面说明会发送当前问题与最近笔记，密钥不进入浏览器。

实现依据：[Responses function calling](https://developers.openai.com/api/docs/guides/function-calling) 与 [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)。服务提供问题存在性的出处，不把出处当成答案证据。模型输出经过类型、字段、长度、问题 ID 与来源版本检查；这些工程检查不验证科学结论。

## 内在动力的实现

自主性：可以自由选择、跳转、停下、直接运行、回到旧问题。没有签到、积分、排名或强制步骤。

胜任感：反馈来自自己看到的模型行为、对不同解释的区分、可回看的思考变化。保存记录不以结论正确或字段填满为条件。

好奇心：从一个具体问题看到另一领域及相似处背后的差异，提出新的追问。六个主题不是六个待完成任务。
