# 从海图到研究现场：岛屿体验第三轮

## 设计问题

本轮沿用既有矿物色、手绘建筑与海图，不创建另一套产品皮肤。基线截图见 `.impeccable/review/v3-before-atlas.png` 与 `v3-before-island.png`。

迭代前问题：登岛信息板与分区面板遮挡主要建筑；分区以访问顺序锁定；小地图与真正建筑没有共同位置定义；楼层按两条内容切分，容易把信息分页误读为研究深度；建筑之间主要依赖文字标签区分；进入内容后与出发问题、外部来源和下一处去向的联系薄弱。

## 方向契约

THESIS：同一问题在海图、岛屿、建筑和研究材料之间持续可辨认。空间组织信息，访问顺序由好奇心决定。
OWN-WORLD：保留矿物纸面、领域海色、等距建筑和清晰墨线；不同研究用途有不同建筑轮廓，路网来自真正建筑坐标。
STORY：在海图选择问题；抵达后读懂主疑问和去处；定位建筑；进入明确的材料或研究动作；携带原问题返回或转向另一岛。
FIRST VIEWPORT：收紧上方信息，左侧保留问题与精简去处，主要视野交给岛屿；选择建筑时相机与说明同步，阅读时仍可辨认所在位置。
FORM：在现有 L0—L1—L2 体验内做代码驱动的系统扩展，保留身份与现有科研功能；不采用另起身份的概念抽签。
FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 每一层的职责

| 层次 | 帮助理解 | 可做的事 | 延后展示 |
| --- | --- | --- | --- |
| 海图 | 问题分布与已记录关系 | 搜索、缩放、选择航向、登岛 | 建筑内部条目 |
| 岛屿 | 主问题与几种研究切入点 | 定位/进入建筑、查看背景、回到海图 | 全部证据正文 |
| 建筑 | 此处的用途和实际材料 | 按内容主题选择房间、查阅来源、切换去处 | 不相关建筑内容 |
| 材料 | 原文、出处、推测和观察的区别 | 阅读、核对、保留追问、接续可用工作台 | 不以访问状态代替科研结论 |

## 空间与信息规则

- 建筑、定位图、相机目标和路径共用稳定站点 ID 与位置定义。
- 问题墙呈现疑问；文献阁呈现可核对出处；白板厅呈现解释差异；数据台区分真实数据与账本计数；实验坊呈现方法；展厅区分已有结果和预期影响；散木园保留未完成与失败线索；讨论亭的编辑角色不冒充在线参与者；码头提供实际可用的返回与跨岛入口。
- 有内容就能访问。没有内容时说明缺口，不用点击解锁，也不凭占位材料塑造繁荣。
- 空间上的靠近和道路只表示界面组织，不表示机制相同；岛屿地形不代表科研价值。
- 旧访问、楼层与研究笔记保持兼容；访问不加分，不产生事实或账本关系。
- 既有夜间回放、来源撤回提示、结构提案、移栽操作继续保留。

## 信息与旧数据兼容

- 房间按来源、开放问题、不同解释、方法等语义合并原楼层；全部原楼层地址与材料保留。删除八层截断上限。
- 文献缺少编辑摘要时呈现原始引文，不把主问题简介复制成论文摘要。
- 明确空论断列表不会从事件数合成论断建筑。
- 私人追问沿用岛屿札记及 1200 字限制。编辑材料、原文出处、模型观察、个人记录与真实账本继续分别标明。

## 建筑作为信息组织

| 建筑 | 可辨认元素 | 内容与研究动作 |
| --- | --- | --- |
| 问题墙 | 开放弧墙、问题纸片、讨论台阶 | 从主问题进入开放子问、问题改写和暂时回答 |
| 文献阁 | 高书架、蓝色屋顶、可见书脊 | 区分论据摘要与原始来源，直接查阅引文 |
| 白板厅 | 开放结构、相对布置的白板 | 对照不同解释和未解决张力 |
| 数据台 | 开放仪器平台、图表与测量符号 | 辨认测量内容、编辑数据和账本计数 |
| 实验坊 | 锯齿屋顶、设备与工作台 | 阅读方法、尝试线索，接续可操作的简化模型 |
| 散木园 | 未完成构件、片段式陈列 | 保存失败边界、未完成工作和可继续追问之处 |
| 展厅 | 展示墙、入口与采光顶 | 查看已收录结果及其来源，区别预期影响 |
| 讨论亭 | 开放亭顶、围桌座位 | 阅读非正式想法和编辑角色视角 |
| 渡口 | 栈桥、船只、指路牌 | 返回海图，携带问题转向其他空间 |

建筑几何复用于真实地图、导览缩略图、抵达预览和阅读标题区。不同设备不另造站点位置。分区是几种研究切入方式，不能被理解成必须按顺序完成的科研流程。

## 交互细节

- 总览按实际海岸包围范围取景，避免固定圆岛假设裁切庭院型海岸；选择建筑后相机对准该建筑的实际位置。
- 抵达预览呈现一条本建筑已有材料；明确点击“进入”后切换到阅读尺度。桌面仍保留建筑，手机使用完整阅读视口。
- 步行线置于建筑下面，当前建筑以地面选中环和标签表达；道路线不作为科学关系输出。
- 内容标签支持方向键、Home/End。关闭阅读恢复入口焦点；切换内容时回到阅读起点。
- 海图在登岛前保存观察位置；常规场景重建也保留位置。探索舟仍使用原有独立航行姿态。
- 夜间使用独立正文强调色和按钮前景色；尊重减少动态效果设置。
- 原有专用样板岛 `machine-curiosity` 的 QFT、实时会话与专属内景保留。本轮空间系统应用于通用生成岛，而非删除这些旧有研究功能。
