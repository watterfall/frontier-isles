# 问题群岛

问题群岛面向对前沿科学有好奇心的研究者、学习者和跨领域构建者。它把研究问题、来源和已记录的关系组织成可探索的群岛，帮助人找到值得继续追问的问题，辨认不同领域之间可借用的方法及其失效边界。

用户可以从海图搜索或接近问题群，登上一座岛，按自己的兴趣选择问题墙、文献阁、白板厅、数据台、实验坊等研究空间。在建筑中阅读原始出处、编辑材料和不同解释，留下私人追问，再转向另一个空间或回到海图。建筑、选择反馈与阅读入口使用稳定的身份和空间地址。手机可进入同一岛屿与材料；无 GPU 模式保留可操作的建筑地图。

探索依靠好奇心、理解和自主选择推进。已有材料可直接访问；访问次数不解锁知识，不产生积分、等级或科学结论。私人岛屿札记保存在当前浏览器，可通过既有考察舟回看、导出；这不是跨设备同步或账本发布。

研究事实与界面组织分开：追加式账本及其来源记录提供可追溯材料；空间接近、共享主题、建筑规模和模型行为本身都不能建立科学关系。原始引文与编辑摘要分别呈现，缺少摘要时不编造。岛上的编辑角色不代表此刻在线活动，结构迁移提案也不自动成为有效结论。

领域碰撞工作台支持比较问题、明确对应关系、提出假设并设计检验。可选 AI 工具调用受已配置的服务能力约束，接入 xFrontier 的数据和 MCP 原语；本地协议与界面测试不证明模型建议的科学质量。模型工作台中的简化同步、扩散等实验支持观察与思考，不直接验证岛屿研究。

本说明记录当前实现和产品边界。具体模型服务可用性、真实研究价值、使用者体验和线上部署状态必须分别验证；不能从本地构建或截图推导。
